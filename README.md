# 坦克世界原生输入法 V13 测试版

目标客户端为国服 2.4.1.1 x64。实现依据是会话 `session-982d148b-90b2-42f9-b3f3-06947c2d339e` 的[可行性研究](../坦克世界原生输入法接入可行性.md#L33-L39)。

V2 通过客户端的 Python 2.7 原生扩展加载 Windows 文本服务（TSF 或 IMM），解决 V1 缺少 `_ctypes` 导致模组启动失败的问题。模组从原版 Scaleform 输入框读取光标位置和选区，确认后向同一个输入框应用结果。发送与搜索继续由游戏处理。接入范围包括车库聊天和联系人搜索，以及战斗聊天。

## 安装与实机验收

退出游戏后，把上一版的 `.wotmod` 和原生模块移出 `mods/2.4.1.1/`。首次测试请暂时移出其他输入法模组和探针。把安装包解压到游戏根目录，`mods/2.4.1.1/` 下应出现 `wot.native.ime_1.0.12.wotmod` 和 `_wot_native_ime.pyd`。回退时退出游戏并移出这两项。[V13 测试包](dist/WotNativeIme_V13.zip)

使用默认配置的微软拼音和当前使用的搜狗拼音，各验证一遍。先测位于屏幕原位置的车库公共聊天框，再测联系人搜索和战斗聊天。

| 操作 | 画面判据 |
| --- | --- |
| 输入拼音、退格，再按 `Esc` | 原版输入框保留焦点，候选面板顶部的拼音随组字更新，取消后消失 |
| 分别用空格、数字和鼠标确认候选 | 每次只上屏一次，聊天内容仍在编辑框中 |
| 将光标移至现有文本中部再选词 | 只在光标处插入，前后原文保留 |
| 选中一段已有文字再选词 | 只替换选区 |
| 选中文字后组字，再按 `Esc` 或切换窗口 | 候选消失，原文保留 |
| 确认候选后单独按一次 `Enter` | 由游戏按原有规则发送聊天或搜索 |

可读的 TSF 和 IMM 候选共用光标旁面板，组字结束时清理候选。V13 在支持的输入框获得焦点时隐藏游戏原有输入法状态栏。模组有候选可显示时，尝试隐藏同一 Scaleform 舞台上可识别的原版候选组件。拼音预览保留输入法提供的分隔符，也读取与当前组字匹配的 TSF 读音或 IMM 分段数据。空格和数字选词由当前输入法处理，提供确认接口的 TSF 候选也支持鼠标选择。仅提供私有候选窗口的输入法仍使用其原候选界面。

在游戏的 `game.log` 中搜索 `[WotNativeIme]`。`V13 mod loaded` 表示模组初始化，聚焦支持的输入框后应出现 `TSF attached` 或 `IMM attached`。`overlay` 记录候选行数和鼠标选择接口状态。`immRead` 记录 IMM 列表读取次数和成功次数，`owned` 记录当前接管的列表。每次启动最多 40 条诊断，仅记录状态和计数。输入拼音后停两秒再确认，以便采集候选状态。

## 构建与验证

在 Windows 的 MSYS Bash 中运行 `bash build.sh`。使用工作区既有的 Flex、Temurin 21、Python 2.7 以及 x64 MinGW，可通过 `CXX` 指定编译器。

构建会检查 `_ctypes` 不可用时仍能加载原生扩展，在 Windows TSF COM 编辑会话中检查选区替换和组字回调，并校验最终安装包结构。候选窗和按键行为需要在游戏里测试。
