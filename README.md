# 坦克世界原生输入法 V1.0.3

适用于《坦克世界》国服 2.4.1.1 x64。车库聊天、联系人搜索和战斗聊天使用原版输入框。Windows 当前输入法负责组字、选词和确认，游戏负责发送或搜索。候选和组字预览显示在光标旁，预览按输入法提供的文本显示。候选面板仅供查看，使用当前输入法的数字键或空格选词。

## 安装和回退

1. 退出游戏，将旧版 `wot.native.ime_*.wotmod`、`wot.native.ime.stock-filter_*.wotmod` 和 `_wot_native_ime.pyd` 移出 `mods/2.4.1.1/`，一并保留作为备份。
2. 将 [V1.0.3 完整安装包](dist/WotNativeIme_V1.0.3.zip)解压到游戏根目录。`mods/2.4.1.1/` 下应出现 `wot.native.ime_1.0.3.wotmod`、`_wot_native_ime.pyd` 和 `wot.native.ime.stock-filter_1.0.3.wotmod`。
3. 在公共聊天输入一组拼音，确认光标旁只出现一个候选框。按数字选词后，文字应只上屏一次，候选框随即关闭。随后按 `Enter` 由游戏发送。在联系人搜索和战斗聊天也可按此方式检查。

去重模组覆盖客户端 Scaleform 的 `gui/flash/ime.xml`，会影响其他使用该配置的游戏输入框。只回退去重功能时，退出游戏并移出去重模组。完整回退时移出以上三个文件，再放回同一版本的备份。

## 输入法范围和验证

| 客户端语言 | 登记条数（含版本与别名） | 关闭旧候选绘制 | 登记的主要输入法 |
| --- | ---: | ---: | --- |
| 简体中文 | 56 | 54 | 微软、搜狗、QQ、谷歌、百度、必应和 JJ 拼音，全拼、双拼、郑码、智能 ABC、微软/搜狗/QQ/万能/极点五笔、ArrayCL、新仓颉、内码 |
| 繁体中文 | 35 | 31 | 注音、新注音、仓颉、新仓颉、速成、新速成、行列、大易、英数、Big5、Unicode |
| 日文 | 13 | 13 | 微软日文 IME、Google 日本语输入、ATOK 2008/2009/2013 |
| 韩文 | 11 | 11 | 微软韩文 IME 和微软韩文输入器 |

打包时核对全部 115 条登记，只替换 109 条旧候选绘制标记，保留两条普通美式键盘与四条原本已停用的登记。输入法通过 Windows TSF/IMM 提供的候选可以进入模组面板，只提供私有窗口的输入法使用自己的界面。

此前在国服客户端实测过微软、搜狗、QQ 和微信拼音的数字选词、单次上屏及收框，也测过联系人搜索和战斗聊天。本次正式版使用自动化回归验证。实机检查还应覆盖选区替换、中间插入、取消或切窗后保留草稿，以及候选面板是否允许鼠标点击穿透至游戏界面。

## 构建

在 Windows MSYS Bash 中运行 `bash build.sh PATH_TO_GUI_PART3_PKG`。参数为已安装客户端的 `res/packages/gui-part3.pkg`，构建仅读取这个资源包。省略参数可生成仅含主模组和原生模块的核心包。构建依赖工作区的 Flex、Temurin 21、Python 2.7 和 x64 MinGW，可通过 `CXX` 指定编译器。

原生模块管理 TSF/IMM 的组字和候选生命周期，Python 桥接游戏视图，ActionScript 管理游戏输入框、光标和候选显示。构建会运行原生模块加载和 Windows TSF 编辑会话测试，并校验安装包及内层模组。运行故障可在游戏日志中搜索 `[WotNativeIme]`。
