# 坦克世界国服输入法修复

适用于《坦克世界》国服 2.4.2.0 x64。车库聊天、联系人搜索和战斗聊天使用原版输入框。Windows 当前输入法负责组字、选词和确认，游戏负责发送或搜索。候选和组字预览显示在光标旁，预览按输入法提供的文本显示。候选面板仅供查看，使用当前输入法的数字键或空格选词。

## 候选框定位修复

原版中文候选框有时会偏离输入框，甚至出现在屏幕外。在支持的聊天和搜索框内，模组把候选列表放在文字光标旁；下方空间不足时优先向上展开，并将面板限制在可见区域。V1.0.7 将去重规则从搜狗、QQ 拼音扩展到全部已启用的简体和繁体中文输入法登记，以避免其他输入法也出现原版和模组两套候选，或继续显示错位的原版候选框。

## 安装和回退

1. 退出游戏，将旧版 `wot.native.ime_*.wotmod`、`wot.native.ime.stock-filter_*.wotmod` 和 `_wot_native_ime.pyd` 移出 `mods/2.4.2.0/`，一并保留作为备份。
2. 将 V1.0.7 完整安装包解压到游戏根目录（[已发布版本](https://github.com/itkzj/wot-native-ime/releases)）。本次构建的 `mods/2.4.2.0/` 下包含 `wot.native.ime_1.0.7.wotmod`、`_wot_native_ime.pyd` 和 `wot.native.ime.stock-filter_1.0.7.wotmod`。
3. 在公共聊天输入一组拼音，确认光标旁只出现一个候选框。按数字选词后，文字应只上屏一次，候选框随即关闭。随后按 `Enter` 由游戏发送。在联系人搜索和战斗聊天也可按此方式检查。

游戏小更新只更换版本目录时，退出游戏，将上述三个同版文件一起放入新版本的 `mods/<版本>/`。V1.0.4 起，脚本读取游戏根目录 `paths.xml` 中的 `.wotmod` 挂载路径，不扫描其他版本。成功后可在 `game.log` 搜索 `[WotNativeIme] native module:` 核对实际加载路径。若客户端改变了游戏接口、Python 运行时或输入法去重配置，仍需重新适配；移动文件不代表新版已通过兼容性验证。

去重模组覆盖客户端 Scaleform 的 `gui/flash/ime.xml`，会影响其他使用该配置的游戏输入框。只回退去重功能时，退出游戏并移出去重模组。完整回退时移出以上三个文件，再放回同一版本的备份。

## 输入法范围和验证

| 客户端语言 | 登记条数（含版本与别名） | 关闭旧候选绘制 | 登记的主要输入法 |
| --- | ---: | ---: | --- |
| 简体中文 | 56 | 54 | 全部启用的中文输入法候选，包括拼音和五笔 |
| 繁体中文 | 35 | 31 | 全部启用的中文输入法候选，包括注音、仓颉、速成和行列 |
| 日文 | 13 | 0 | 全部保留原版 |
| 韩文 | 11 | 0 | 全部保留原版 |

**兼容性取决于输入法提供的 Windows 接口。** 在上面列出的游戏输入框中，输入法通过 Windows 文本服务框架（TSF）或输入法管理器（IMM）提供组字文本、候选列表和确认结果时，模组可以在光标旁显示候选，键盘选词由输入法处理。未在游戏登记表中列出的输入法也可能直接工作。如果输入法只在私有窗口绘制候选，并且只向游戏提交最终文字，文字可能正常上屏，但模组无法显示该候选列表。

V1.0.7 的输入桥只在支持的聊天或搜索框内接管活动的中文输入法。简中、繁中共有 91 条登记（含别名），其中 85 条需要关闭旧候选绘制，另有 2 条普通键盘和 4 条已停用登记沿用原值。去重配置在客户端全局生效：其他读取该配置的输入框也可能失去原有的中文候选框，而模组只在支持的字段显示替代面板。日文、韩文配置段保留原版。

此前在国服客户端实测过微软、搜狗、QQ 和微信拼音的数字选词、单次上屏及收框，也测过联系人搜索和战斗聊天。本次正式版使用自动化回归验证。实机检查还应覆盖选区替换、中间插入、取消或切窗后保留草稿，以及候选面板是否允许鼠标点击穿透至游戏界面。

## 构建

在 Windows MSYS Bash 中运行 `bash build.sh PATH_TO_GUI_PART3_PKG`。参数为已安装客户端的 `res/packages/gui-part3.pkg`，构建仅读取这个资源包。省略参数可生成仅含主模组和原生模块的核心包。构建依赖工作区的 Flex、Temurin 21、Python 2.7 和 x64 MinGW，可通过 `CXX` 指定编译器。

原生模块管理 TSF/IMM 的组字和候选生命周期，Python 桥接游戏视图，ActionScript 管理游戏输入框、光标和候选显示。构建会运行原生模块加载和 Windows TSF 编辑会话测试，并校验安装包及内层模组。运行故障可在游戏日志中搜索 `[WotNativeIme]`。
