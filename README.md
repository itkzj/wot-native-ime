# 坦克世界国服输入法修复 · 1.0.8-beta

适用于国服 2.4.2.0 x64。游戏语言栏能识别当前输入法时，使用原版候选、键盘选词和提交。语言栏明确显示 `Not Supported` 时，模组才在支持的中文聊天或搜索框中接入 Windows TSF / IMM，在光标旁显示候选。语言栏还在加载、无法读取或当前字段不受支持时，由游戏处理输入。

原版候选位置修正使用客户端自带的 `res/gui/flash/ime.swf`。当游戏界面缩放使宿主提供的坐标偏离焦点输入框，而按当前舞台倍率换算后落回该输入框时，修正原版列表的位置和贴边处理。1× 缩放、无法取得焦点或无法验证坐标时，沿用游戏自身定位。纯原版搜狗的 1× 对照已在国服实测，这个 beta 在自动缩放下的结果仍需实机确认。

## 安装和回退

1. 退出游戏，把先前安装的 `wot.native.ime_*.wotmod`、`wot.native.ime.stock-filter_*.wotmod` 和 `_wot_native_ime.pyd` 一起移出 `mods/2.4.2.0/`，留作备份。上一个测试包也叫 `1.0.8-beta`，升级时需要同时替换主模组和原生模块。
2. 将新 ZIP 解压到游戏根目录。`mods/2.4.2.0/` 下应有 `wot.native.ime_1.0.8-beta.wotmod` 和 `_wot_native_ime.pyd`。游戏会继续使用自己的输入法登记表。游戏日志中的 `[WotNativeIme]` 可用于核对启动版本和原生模块加载路径。
3. 回退时退出游戏，移出这两个文件，再放回同一旧版本的整套备份。

## 实机检查

- 保持平时的界面缩放。在公共聊天和联系人搜索中切到原版能识别的搜狗拼音，先在屏幕中间组字，再把聊天窗拖到底边。检查白绿原版候选是否跟随光标并留在画面内。用 1× 缩放复测原来位置正确的情形。
- 在同一输入框切到游戏显示 `Not Supported` 的中文输入法。确认只出现一个模组候选框，数字或空格选词后文字只上屏一次，再按 `Enter` 才发送。切回搜狗后应恢复原版候选。战斗聊天也可按相同步骤复测。
- 在模组支持范围以外的字段、非中文键盘、组字中失焦或按 `Esc` 时，检查是否保留原草稿。模组候选面板仅供查看，键盘选词由输入法负责。

## 构建

在 Windows MSYS Bash 中运行 `bash build.sh E:/Games/World_of_Tanks_CN/res/packages/gui-part3.pkg`，按本机安装位置替换参数。构建从该客户端定位 `paths.xml` 和散装候选资源 `res/gui/flash/ime.swf`，使用工作区已有的 Flex、Temurin 21、Python 2.7 和 x64 MinGW。输出在 `dist/` 下。脚本会运行 Windows TSF、消息路由和包内容校验。
