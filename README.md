# 坦克世界国服输入法修复 · 1.0.8-beta

适用于国服 2.4.2.0 x64。游戏语言栏能识别当前输入法时，使用原版候选、键盘选词和提交。语言栏明确显示 `Not Supported` 时，模组才在支持的中文聊天或搜索框中接入 Windows TSF / IMM，在光标旁显示候选。语言栏还在加载、无法读取或当前字段不受支持时，由游戏处理输入。

原版候选位置修正使用客户端自带的 `res/gui/flash/ime.swf`。当游戏界面缩放使宿主提供的坐标偏离焦点输入框，而按当前舞台倍率换算后落回该输入框时，修正原版列表的位置和贴边处理。1× 缩放、无法取得焦点或无法验证坐标时，沿用游戏自身定位。国服 2.4.2.0 已通过游戏内测试。搜狗拼音在公共聊天的 1× 和自动 2× 缩放下都能跟随输入位置。战斗聊天按实际显示的输入框修正纵向位置，长候选行在连续输入时复用已有排版。

两套候选列表共用灰橄榄渐变、字体、行高和选中行左侧的细金线。使用原版输入法时，候选顺序、序号和组字提示仍由游戏和输入法提供。

## 安装和回退

1. 退出游戏，把先前安装的 `wot.native.ime_*.wotmod`、`wot.native.ime.stock-filter_*.wotmod` 和 `_wot_native_ime.pyd` 一起移出 `mods/2.4.2.0/`，留作备份。上一个测试包也叫 `1.0.8-beta`，升级时需要同时替换主模组和原生模块。
2. 若 `res_mods/2.4.2.0/gui/flash/ime.swf` 来自其他模组，先备份。将新 ZIP 解压到游戏根目录，覆盖同名的旧诊断文件。`mods/2.4.2.0/` 下应有 `wot.native.ime_1.0.8-beta.wotmod` 和 `_wot_native_ime.pyd`，`res_mods/2.4.2.0/gui/flash/` 下应有 `ime.swf`。游戏继续使用自己的输入法登记表。
3. 回退时退出游戏，移出上述三个文件，再放回之前的备份。

## 实机检查

- 保持平时的界面缩放。在公共聊天和联系人搜索中切到原版能识别的搜狗拼音，先在屏幕中间组字，再把聊天窗拖到底边。检查灰橄榄色候选列表是否跟随光标并留在画面内，选中行左侧是否有细金线。用 1× 缩放复测原来位置正确的情形。
- 在同一输入框切到游戏显示 `Not Supported` 的中文输入法。确认只出现一个模组候选框，数字或空格选词后文字只上屏一次，再按 `Enter` 才发送。切回搜狗后应恢复原版候选。战斗聊天也可按相同步骤复测。
- 在训练场保持微软拼音中文模式，先按住 W 并松开。打开战斗聊天，选词并发送一句中文，随后再按住 W 并松开。两次都应能起步、停车；重开聊天应还能中文选词。另用 Esc 关框复测一次。若进场时游戏窗口没有 TSF 焦点文档，关框后模组会核对当前文档。仍属于本次聊天、且其他界面没有占用控制时，恢复进场时的空文档焦点。驾驶期间游戏自行处理 WASD 和 Shift。
- 在模组支持范围以外的字段、非中文键盘、组字中失焦或按 `Esc` 时，检查是否保留原草稿。模组候选面板仅供查看，键盘选词由输入法负责。

## 构建

在 Windows MSYS Bash 中运行 `bash build.sh E:/Games/World_of_Tanks_CN/res/packages/gui-part3.pkg`，按本机安装位置替换参数。构建从该客户端定位 `paths.xml` 和散装候选资源 `res/gui/flash/ime.swf`，使用工作区已有的 Flex、Temurin 21、Python 2.7 和 x64 MinGW。输出在 `dist/` 下。脚本会从同目录的 `scripts.pkg` 加载原版聊天方法，回放普通关框、清空后聊天重新取得焦点及其他界面接管三种情况，并运行 Windows TSF、消息路由和包内容校验。Flash 事件与车辆控制端点由测试模拟。

候选面板的快打回放可单独运行 `node test_candidate_panel.cjs`。它检查连续更新时的文本框复用、背景绘制与位置属性写入次数，以及换行、缩放和贴边定位。
